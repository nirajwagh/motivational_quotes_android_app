# Motivational Quotes Android App

A simple and lightweight **Android app for reading motivational and inspiring quotes**.

Designed with a clean and minimal interface, the app allows users to browse uplifting quotes anytime without distractions.

## Features

* Motivational and inspiring quotes
* Clean and minimal UI
* Lightweight experience
* Fully offline
* No ads

## Download

**[Download APK](https://github.com/nirajwagh/motivational_quotes_android_app/releases/latest)**

If Android blocks installation, enable **Install Unknown Apps** for your browser or file manager.
